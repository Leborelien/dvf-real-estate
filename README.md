# French Real Estate Market Analysis (DVF)

## Business Question
How do property prices per m² evolve by département
and property type, and where is the market most active?

## Technologies
- Python (pandas, requests)
- PostgreSQL
- SQL
- Docker
- Power BI

## Data Source
French government open data: Demandes de Valeurs Foncières (DVF).

## Project Structure
- data/: raw and processed datasets
- src/: Python scripts
- sql/: SQL analysis
- docs/: documentation
- powerbi/: dashboards
